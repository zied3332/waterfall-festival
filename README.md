# Waterfall Festival Platform

A production-ready full-stack festival management platform developed for **Waterfall Festival**, providing a modern website, administrative dashboard, and backend services for managing events, media, tickets, and customer interactions.

The platform is designed with a modular architecture to support future expansion, including AI-powered assistance, analytics, and additional services.

---

# Overview

The platform consists of multiple independent services working together:

- Frontend website for festival visitors
- Administrative dashboard
- Backend REST API
- PostgreSQL database
- Future AI assistant integration
